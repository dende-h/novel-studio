# 作品全体の検索・置換 仕様書（COT-29）

- 要件: COT-32 ／ 設計: COT-33 ／ プロトタイプ: `docs/specs/COT-29/prototype.html`（ローカル）
- 状態: 独立レビュー通過（Round 2）。本体実装済み。検証結果は `validation.md`。

## 何を作るか
現在の作品の全話を検索し、話名と前後の文から場面を探せるようにします。
結果から本文の一致箇所へ移動し、1件ずつ、または全件を置換できます。
未保存の下書きを含めて扱い、置換前の本文を履歴に残します。

## 振る舞い
- **FR-1** 全話を話順・出現順で検索。現在話はdraft、他話はblocksToNotation。大文字小文字・全半角を区別する非重複のリテラル一致。空語は検索しない。改行を含む検索/置換語は対象外。結果は話名・1始まりの行番号・前後最大30文字・一致強調。100件ずつ追加表示し、全件数は保持する。
- **FR-2** 結果を押すと下書きを保存して該当話を開き、一致範囲を選択・行へスクロール。保存後は位置を再計算する。保存失敗/古い結果/位置対応が一意でない場合は移動を中止し、下書きを保つ。mobileは本文タブにしてパネルを閉じる。
- **FR-3** 参照に重ならない結果の「この1件を置換」でその出現だけを保存し再検索。空の置換語は削除、同じ語は操作不可。`$&`などもそのまま文字として扱う。
- **FR-4** 全置換は参照を除いた置換可能件数・話数・履歴保存の確認を経て実行。キャンセルは変更なし。確認後に内容が変わっていれば中止する。置換語に検索語を含んでも追加で置換しない。
- **FR-5** 保存スキーマは変更しない。本文記法（ルビ・傍点・参照を含む）を検索する。`[[…]]` の中身・括弧・境界に重なる一致は置換対象外。未終端の参照は行末まで保護し、参照内の検索・移動は維持する。本文以外を変えない。変更話だけparse/reconcileし、未変更話のblocks/idを保つ。
- **FR-6** 下書きを反映した置換前Workをappendで履歴保存してから、置換後Workを1回保存する。append直後に履歴一覧と次回saveのappendフラグを反映し、本文保存失敗でも履歴を保護する。履歴失敗時は本文を書かない。本文保存済みの補助処理失敗で置換を再実行しない。updatedAt更新とstore通知で既存同期を起動する。
- **FR-7** 作品変更・自動保存を直列化し、同期のローカル書き込みと排他を共有する。ロック後に元作品の全内容と検索元テキストを検証し、変化/削除なら中止する。置換中は本文と作品変更を停止する。既存の下書きを捨てない。

## 画面
`#/write` の「置換」を「検索・置換」に変更。「この話」は下書きへの即時適用を維持し、参照を置換から除外。「作品全体」は検索入力・置換入力・結果・全件置換を表示します。
PCは幅360pxの浮きパネル、mobileは全幅シートで最大85dvh。検索中/初期/話なし/0件/保存失敗/古い結果を表示します。ゲスト・無料会員・オフラインでも使えます。
番号①入口②対象③結果④全件置換⑤移動はプロトタイプと対応。現状は `screens/writer-*.png` と `screens/replace-*.png`。

参照の結果には「用語集の参照・置換対象外」を表示します。参照だけの場合は置換を無効化し、本文・履歴を書き換えません。別名の自動登録は行いません（2026-10-06のユーザー指示による改訂）。

## テスト
core: 一致条件・記法・絵文字・空文字・1件/全件・置換語の再検索禁止。store/storage/sync: 先行save・同期との競合、履歴/本文失敗、transaction abort、失敗後の履歴保護、他フィールド保持、補助処理失敗。
UI/e2e: 2話のdirty検索→結果移動→1件/全件/キャンセル→再読込→履歴復元をPC・393pxで検証。性能測定条件は要件定義に従います。

## 守ること
coreからReact/UIを参照しません。新しい依存は不要です。共通Button/Input/Dialog/ConfirmDialog/useToastを使い、shadcnコピーは変更しません。
古い作品の任意フィールド・本文表示・同期/publish/MCP契約を維持します。本文だけを変更し、用語集の項目名は改名しません。公開版を自動更新しません。
Web Locks非対応時は同タブ内の排他に限られ、複数タブの後続保存に対する既存制約が残ります。

## やらないこと
正規表現・曖昧検索・複数作品検索・本文以外の検索/置換・用語集改名・検索索引の保存・新API・全話一括復元UI。
