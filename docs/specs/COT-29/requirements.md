# 要件定義 — COT-29 作品全体の検索・置換

## 背景と目的
長編・連載を書く作者が、各話を開き直さずに場面を探し、名前や表記を統一できるようにします。現在の作品内に限り、本文を検索し、確認しながら1件ずつ、またはまとめて置換します。

## 機能要件
### FR-1 全話検索
- Given 現在の作品 / When 検索語を入力 / Then 全話の記法テキストを大文字小文字・全半角を区別してリテラル検索し、作品の話順・出現順で表示する。現在話だけは保存済み blocks でなく draft を検索する。
- Given `aaa` / When `aa` を検索 / Then 重ならない一致1件。空白はそのまま扱い、検索語の trim はしない。空文字は検索せず置換不可。正規表現・改行を含む検索語は扱わない。
- Given 結果 / When 一覧を表示 / Then 話名・1始まりの改行基準の行番号・一致語と前後最大30文字の抜粋を表示する。長文は省略記号、一致は強調する。改行は抜粋内で空白表示。
- Given 初期/0件/話なし / When パネルを開く・検索 / Then それぞれ「検索する語を入力してください」「見つかりませんでした」「話を追加すると検索できます」を表示する。
- Given 本文・話順・話名が変わる / When 次の表示 / Then 一覧・件数を更新する。新しい検索完了まで古い結果の移動・置換を無効にする。
### FR-2 結果から移動
- Given 同話/別話の結果 / When 結果を選択 / Then 未保存本文を保存してから対象話を開き、本文タブを表示し、一致範囲を選択して該当行を見える位置にスクロールする。モバイルではパネルを閉じ、本文へフォーカスする。
- Given 保存失敗または古い結果 / When 移動 / Then 話を切り替えず、下書きを保持してエラーまたは再検索を案内する。正規化で位置が変わる場合は保存後のテキストで再検索し、文脈・出現順位が一意に対応しなければ移動を中止する。
### FR-3 1件置換
- Given 最新結果と置換語 / When その行の「この1件を置換」 / Then 選んだ通常本文の出現だけを置換して保存する。参照に重なる一致は置換不可。再検索して残件を表示し、同じ話の他の出現は変えない。
- Given 空の置換語 / When 置換 / Then 該当文字列を削除する。検索語と置換語が同じなら置換不可。置換語中の `$&`・`$1` は文字そのまま扱う。改行を含む置換語は不可。
### FR-4 全件置換
- Given N件/M話 / When 「すべて置換」 / Then 「N件を置換しますか？」と「M話の本文を変更します。置換前の本文は履歴に残ります」を表示する。空の置換語は「『検索語』を削除します」も表示する。
- Given 確認 / When キャンセル / Then 本文・履歴・更新時刻は変わらない。確定時に作品・下書きが変わっていれば保存せず再検索を促す。
- Given 確定 / When 保存成功 / Then 検索時点の重ならない一致のうち、参照に重ならないものだけを全話で同時に置換する。置換語に検索語を含んでも追加置換しない。成功件数を通知する。
### FR-5 データ・ロジックの境界
- Given `[[名前]]` または未終端 `[[名前` / When この話・全話の1件/全件置換 / Then 中身・括弧・境界に重なる一致を除外する。未終端は行末まで保護。検索・移動は可能、結果は「用語集の参照・置換対象外」を表示する。置換確認の件数・話数には含めない。参照だけなら保存・履歴追加なし。別名・未解決・装飾付き参照も同じ扱い。
- Given 旧作品/小説/脚本 / When 検索・置換 / Then 現行の Work/Episode/Block スキーマで読み書きできる。本文のルビ・傍点・参照は記法として検索対象。用語集の項目名自体は改名しない。
- Given 本文以外の情報 / When 置換 / Then タイトル・用語集・作者メモ・表紙・公開設定・別作品・構造・演出譜を変更しない。未変更話は元の blocks/id を維持し、変更話は reconcileBlockIds を通す。
### FR-6 履歴・保存・同期
- Given 下書きを反映した置換前 Work / When 1件/全件置換 / Then 本文保存前に append で履歴を確実に保存し、次の自動保存の集約から保護する。現在話以外も既存履歴パネルで話を切り替えて復元できる。
- Given 履歴保存失敗 / When 置換 / Then 本文は変えない。Given 本文保存失敗 / When 置換 / Then 成功を表示せず下書き・本文を保持する（追加済み履歴は残ってよい）。再試行時は最新内容を再検証する。
- Given 本文保存成功 / When 通知 / Then work.updatedAt を増やし、ストア更新で useAutoSync の購読を起動する。同期は有料かつ有効な場合のみで、オフラインでもローカル成功を維持する。
- Given 保存後の活動記録/一覧再取得失敗 / When 通知 / Then 本文保存済みとして扱い、置換を再実行しない。
### FR-7 下書き・競合
- Given 未保存編集 / When 検索・置換 / Then その編集を結果・置換前履歴・保存後本文のすべてに含める。置換のために先に save を呼んで正規化しない。
- Given 自動保存・用語集更新・話追加/削除・同期の受信が進行中 / When 置換 / Then 保存処理を直列化し最新作品を検証する。置換中は本文と作品変更操作を停止し、完了/失敗後に再開する。古い非同期処理が置換結果を上書きしない。
- Given 外部で作品が更新/削除された / When 保存直前 / Then 全内容の比較で検出し保存を中止する。現在の下書きを捨てずに再検索・競合解消を促す。

## 非機能要件
- ゲスト・無料会員・有料会員に同じローカル機能を提供。検索のためにネットワーク送信しない。公開版は自動更新しない。利用者が通常の公開操作をしたときだけ反映。
- アクセシビリティ: ラベル、キーボードで結果と置換を操作、件数は aria-live、Esc で閉じ入口にフォーカスを戻す。タップ領域44px以上。
- 検索入力は150ms debounce、IME確定後に検索。100万 UTF-16 単位/200話/1万件 fixture で検索純関数を50回計測し中央値200ms以下を目標とする（CI時間を合否にせず測定環境を記録）。一覧は100件ずつ「さらに表示」で追加し、全件数・全件置換は未表示分も含む。検索中の閉じる操作を妨げない。

## 後方互換性チェック（プロジェクト共通規約 CLAUDE.md の各項目）
- スキーマ: 変更なし。新規保存フィールドなし。
- 旧形式の読み出し: 既存 blocksToNotation/parseEpisodeBody を使用。旧作品 optional フィールドを変更しない。
- 表示先の維持: 既存本文・用語集・履歴・現在話だけの置換を維持。
- 部分更新で他の欄を落とさない: 最新 Work/Episode を spread、変更 blocks と更新時刻だけを変更。
- 削除は明示操作だけ: レコードの削除なし。検索語の削除は空置換語という明示操作。
- 配信契約（publish・同期 API・MCP）: 型・API・バージョン不変。既存同期通知を使用。
- 破壊的変更時の退避・回帰: 破壊的スキーマ変更なし。旧形式と記法・未変更フィールドの回帰テストは実施。

## 仮定と未決事項
- 仮定: 初期対象は全話の本文記法。既存「この話」の置換を残し、同じ入口に「作品全体」タブを追加する。
- 仮定: 1件ずつの確認は結果行の抜粋・置換ボタンで行う。全置換は確認必須。
- 仮定: 多数話の一括復元UIは追加しない。既存履歴で各話を復元する。
- 未決: 要件を左右する未決事項なし。性能の測定結果は実装時に記録する。

## 対象外
正規表現・曖昧一致・大小文字無視・タイトル/用語集/プロット等の検索、複数作品横断、用語集改名、検索索引の保存、新たな公開・MCP API、作品全体を一度に復元するUI。
