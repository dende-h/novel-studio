# 要件定義 — COT-45 集中モードとタイプライタースクロール

## 背景と目的
書き手が周辺の操作を隠し、入力行を見失わずに執筆できるようにする。本文の保存経路と原稿の形式は維持する。

## 機能要件
### FR-1 集中表示
- Given 話の本文を開いている / When 「集中モード」か Alt+Shift+F / Then トップバー、左右パネル、プレビュー、通常ツールバー、文字数、脚本チェックを隠し、本文と最小操作列（終了・追従・全画面・保存状態）を表示する。
- Given 集中中 / When 同じキーか「集中モードを終了」 / Then 元のパネル開閉・モバイルの表示面に戻る。本文textareaを再マウントせず、未保存本文・選択範囲・undoを保つ。集中開始時は本文にフォーカスする。
- Given IME変換中・キーリピート・ダイアログ表示中・本文以外の画面 / When キー操作 / Then モードを切り替えない。話がない場合は入口を表示しない。
- Given サジェスト表示中 / When Escape / Then 候補だけ閉じる。Escapeで集中モードは終了しない（脚本のEsc→Tabも維持）。
### FR-2 全画面
- Given 集中中かつAPI対応 / When 「全画面にする」 / Then 明示クリックからrequestFullscreenし、成功時だけ「全画面を終了」に変わる。
- Given 拒否または非対応 / When 全画面操作 / Then 本文と集中状態を保つ。非対応は入口非表示、拒否は「全画面にできませんでした」と通知する。
- Given 全画面 / When ブラウザのEscape・外部終了 / Then fullscreenchangeで表示を追従し、集中は継続する。集中終了・画面離脱では本機能が開始した全画面だけを終了する。ブラウザ自身のF11は管理しない。
### FR-3 入力行の追従
- Given 「入力行を中央に保つ」がオン / When 入力確定、改行、折返し、矢印移動、クリックでキャレット移動、幅・文字サイズ・可視領域変更 / Then 可視本文領域の中央±1行高にキャレット行の中心が来る。先頭・末尾・空本文も上下の表示余白で成立させ、原稿文字列には余白を足さない。
- Given 範囲選択中・IME変換中・非フォーカス・readOnly / When 描画更新 / Then 中央への自動移動を抑止。変換確定後、選択解除後の次のキャレット操作で再開する。
- Given 手動スクロール / When 過去の行を読む / Then 即座に戻さない。次の本文入力・キャレット操作で再開。オフでは通常のtextareaスクロールを使う。
- Given 通常画面 / When 同じ追従切替をオン / Then 集中表示と独立して追従する。
### FR-4 保存状態
- Given 集中中 / When dirty/statusが変わる / Then 現行の「保存中…」「未保存」「保存済み」「ローカル保存」の判定を共有し、スマホも文字で表示する。保存失敗時の既存トーストを隠さず、成功していない本文を保存済みにしない。
### FR-5 端末設定とスマホ
- Given 初回 / When 話を開く / Then 集中・追従ともオフ。各切替を端末に記憶し、次回本文表示で復元する（全画面は復元しない）。設定保存が失敗しても現在の操作を継続する。
- Given ゲスト・無料・有料・オフライン / When 本文編集 / Then 同じ機能を使える。同期・バックアップに設定を含めない。
- Given 幅393pxでキーボード表示 / When 集中して入力 / Then 終了操作・保存状態を可視領域内に保ち、記法バーを通常は隠す。@候補は入力補助として既存バーを表示し、その高さを中央計算から除く。通常表示に戻れば記法バーも復帰する。

## 非機能要件
キーはaria-keyshortcutsで説明し、全操作をキーボードとタップで利用可能にする。スマホの操作高は44px以上。追従の測定はrAFで1フレームに最大1回、常時ポーリングしない。smoothスクロールを使わない。測定不能なら自動移動を行わず編集を継続する。オフ時にミラー計測をしない。新規依存なし。

## 後方互換性チェック（プロジェクト共通規約 CLAUDE.md の各項目）
- スキーマ：変更なし。全フィールドのoptional性を維持。
- 旧形式の読み出し：変更なし。旧作品を通常どおり開く。
- 表示先の維持：周辺欄は一時的に隠すだけで終了すると戻る。
- 部分更新で他の欄を落とさない：既存setDraft/save経路を維持。
- 削除は明示操作だけ：削除処理を追加しない。
- 配信契約（publish・同期 API・MCP）：変更なし。端末のUI設定のみ。
- 破壊的変更の退避・移行：該当なし。

## 仮定と未決事項
- 仮定：Alt+Shift+F、初期は両方オフ、通常表示でも追従可能。ブラウザ・OSに予約される環境ではボタンを利用する。
- 仮定：保存状態と復帰操作を「本文だけ」の例外とし、入力候補は操作中だけ許容する。
- 未決：実機iOS/Androidでのキーボード・IME検証は実装完了条件。仕様判断の保留なし。

## 対象外
OSの集中設定、自動全画面、行や段落の強調、縦書き入力、原稿形式・会員制限の変更。
