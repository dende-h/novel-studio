## 何を作るか

推敲画面に、作品ごとの決まりを足す。

- **例外：** わざと使っている言葉を「この作品では指摘しない」にする
- **表記の好み：** 表記ゆれを「◯◯にそろえる」で決める

同じ「このまま」や「直す」が重なったら、決まりにするかを提案する。勝手には決めない。決まりは一覧で見えて、戻せる。画面の文言に「辞書」は使わない。

## 振る舞い

### FR-1 例外

- 例外を作れる項目と単位：
  - ら抜き言葉：言葉ごと。活用違い（食べれる／食べれない）は同じ例外
  - 同じ語の連続：文字列ごと
  - 表記ゆれ：組ごと。「書き分けを許す」と呼び、組のどの書き方も指摘しない
- 例外を作れない項目：字下げなどの形の項目は「確認する項目」で止められる。一文の中の同じ助詞は文に結び付く
- 入口：
  - 未判断のカード（ら抜き言葉・同じ語の連続）の「この作品では指摘しない」
  - 表記ゆれのカードのメニューの「書き分けを許す」
- 当たる指摘は、全話で一覧にも本文の印にも出ない
- 推敲の判断の記録は消さない。「直す」と決めた箇所は「直す箇所」に残る

### FR-2 表記の好み

- 表記ゆれのカードのメニュー「この作品の決まりにする」に、書き方ごとの「◯◯にそろえる」を並べる
  - 対象：辞書の組・数（助数詞ごとに算用数字／漢数字）・自動の組
- 好みの書き方は指摘しない
- ほかの書き方は、作品に好みの書き方が無くても指摘する
  - 説明（語）：「「子供」は、この作品の表記「子ども」と違います。」
  - 説明（数）：「「3人」は、この作品の数の書き方（漢数字）と違います。」
- 同じ組に例外と好みは同時に持たない。後から決めたほうに置き換える
  - 好み→例外：カードのメニューから1手
  - 例外→好み：一覧で「戻す」してから、カードのメニューで選ぶ
- くわしい確認の準備ができていても、好みで隠した書き方が自動の表記ゆれとして出直さない（重なりは好みを当てる前の辞書の出現で判定する）

### FR-3 決まりの一覧

- 見出しの「確認する項目」の右に「この作品の決まり（N）」を置く（0件なら数なし）。押すと見出しの下に欄が開く
- 行：中身と「戻す」
  - 例外：「見れる」— ら抜き言葉は指摘しない
  - 書き分け：「子供・子ども」— 書き分けを許す
  - 表記の好み：「子ども」にそろえる（子供・子ども）
  - 数：「人」の数は漢数字にそろえる
- 0件のとき：「決まりはまだありません。指摘のカードから作れます。」
- 欄の最後に「提案しない言葉（N）」。決まりの一覧とまとめて、1つのスクロールに収める（`max-h-48`）
- 「戻す」で行が消えたら、フォーカスは次の行へ移す（無ければ前の行、どちらも無ければ見出し）

### FR-4 提案

- 例外：ら抜き言葉・同じ語の連続の同じ言葉を、全話で3回「このまま」にした
- 表記の好み：同じ組の同じ書き方を、全話で2回「直す」にした
  - 判断の文字列を組の書き方に当て直して数える（「た事が」「る事に」は同じ「事」、「3人」「5人」は同じ「人」の算用数字）
- 出すのは、直前の判断が線を超えたときだけ。1件だけ出す
- 置き場所：「未判断」の絞り込みのチップと一覧の間（一覧のスクロールの外）。未判断が0件になった直後も出す
- ボタン：
  - 例外：「指摘しない」「提案しない」
  - 表記の好み：「◯◯にそろえる」「提案しない」
- 「提案しない」は作品ごとに覚えて同期する。戻すまで同じ提案は出ない
- `role="status"` の入れ物は常に置き、中身だけを入れ替える

### FR-5 保存

- 作品ごとに1件の kv レコード `proofread-rules:<workId>` に置く
- 同期・バックアップ・取り込みの件数（「推敲の決まり：N作品」）・作品の完全削除に乗せる（COT-59 の外した語と同じ配線）
- 壊れた記録は、決まりなしとして読む。他の端末の記録を上書きしない

### FR-6 ヘルプ

- 「推敲する」に、決まりの説明と「用語集に登録した名前は、推敲でもひとつの言葉として扱います。」を足す

### FR-7 「辞書」の言い換え

- 準備中の表示：「（辞書の読み込みは初回のみ）」→「（初回だけ時間がかかります）」
- 読み上げ名：「辞書の読み込み」→「くわしい確認の準備」

## 守ること

- 作品・話・用語集・推敲の判断・外した語のスキーマは変えない
- 新しい記録の核の欄（`workId`・`updatedAt`）は必須にし、中の配列は `.optional().default([])` にする
- 接頭辞は `proofread-rules:`（`proofread:` で始めない）
- バックアップの欄は省略できるようにし、壊れた要素だけを捨てる
- 決まりを消すのは「戻す」と作品の完全削除だけ。推敲の判断の記録は消さない
- 本文は自動で書き換えない

## やらないこと

- 作者の辞書
- 用語集の「作者だけ」の印、読みでルビを振る機能
- 全作品で共有する決まり
- 決まりに沿った一括の書き換え
- MCP から決まりを読み書きすること
- スマホでの推敲画面
