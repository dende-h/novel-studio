# COT-62 元 issue の要約

- 土台: COT-40（推敲画面・直す／このまま）・COT-59（用語集に無い名前・外す）。どちらも stg 反映済み・main 未リリース
- issue 本文は 2026-10-20 のセッションでのユーザーとの対話から私が起こしたもの。以下は要求の材料としてだけ扱う。

## 誰が・何に困っていて・何ができればよいか

- 誰が: コトノハ-leaf- の推敲画面を使う小説の作者
- 困りごと:
  - わざと使っている言葉（「見れる」の口調など）に、話ごと・指摘ごとに「このまま」を選び続けている
  - 「同じ指摘をすべてこのまま」は1話の中にしか効かない
  - 表記ゆれ（子供／子ども）は、両方の書き方が指摘に出るだけ。作品としてどちらにそろえるかを決めておけない
- できればよいこと:
  - 作品ごとの決まりとして、次の2つを持てる
    - 例外：「この作品ではこの言葉を指摘しない」
    - 表記の好み：「この作品の表記：子ども」。選ばなかった側だけを指摘する
  - 選んだ結果を活かす
    - 同じ「このまま」や、同じ向きの「直す」が重なったら、決まりにするかを提案する
    - 裏で勝手に学習しない。押したら決まりになり、一覧で見えて、戻せる

## ユーザーが決めたこと（2026-10-20）

| 論点 | 決定 |
|---|---|
| 個別の辞書登録・選択の学習 | 「作者の辞書」（解析用の語の登録）は作らない。利用者が想像する辞書（入力の候補・ルビ）や、用語集（@ のサジェスト・参照）と混ざって混乱するため |
| 困りごとの置き場所 | 結果ごとに、いまある場所へ割り振る（下の表） |
| 「辞書」という言葉 | 推敲画面の文言では使わない。区切りの調整は裏側の仕組みにとどめる |
| ヘルプ | 「用語集に登録した名前は、推敲でもひとつの言葉として扱います」と一文足す |
| 切り分けた論点 | 用語集の「作者だけ（読者に見せない）」の印、用語集の読みでルビを振る機能。今回は対象外 |
| 学習の形 | 選んだ結果から提案し、作者が1回押して決まりにする（勝手に学習しない） |

困りごとの割り振り：

| 困りごと | 置き場所 |
|---|---|
| 名前・造語 | 用語集だけ（登録すると、推敲でもひとつの言葉として扱われる） |
| 名前でない語が候補に出る | COT-59 の「外す」 |
| わざと使っている言葉 | 推敲画面の「例外」（今回） |
| 表記ゆれのそろえ先 | 推敲画面の「表記の好み」（今回） |

2. ユーザーの指摘：「作者の辞書と用語集の混乱がある」「通常、辞書登録というとルビやサジェストの意味合いが入る」
