  1. 1「EPUB / 電子書籍」の次に「応募原稿」。小説の作品だけに出す（脚本は既存の「脚本（提出用）」）。開いたときに選ばれているのは EPUB のまま。
  2. 2見出しと説明。本文は書き換えずに組むことを最初に伝える。
  3. 3書式のチップ。「指定する」で字数・行数を入れる（A4 は字数 10〜50、B5 は字数 10〜43。行数はどちらも 10〜50）。範囲外はボタンを押せず、欄の下に用紙に合わせた範囲を出す。
  4. 4用紙 A4／B5（横置き・縦書き）。文字の大きさは書式と用紙から自動（8〜14pt）。
  5. 5出力 Word／PDF（印刷）。PDF を選んでいる間、印刷の画面の設定を案内する。
  6. 6ルビ 振る／親文字だけ。枚数はどちらでも親文字で数える。
  7. 7付けるもの。脚本の前付けの枠と同じ見た目。話が1つだけの作品は題名の行を出さない旨を補足に出す。
  8. 8枚数は「選んだ書式での本文の枚数」と「400字詰め換算」を並べる。表紙・あらすじは数えない。
  9. 9Word は既存の「書き出し」、PDF は「印刷して PDF に保存」。字数が 0 の作品（話が無い・空の話だけ）は押せず「本文がありません」。

選んだ書式で組んだ頁を、1マス1文字で並べて印刷します。下は 20字×20行・A4 の本文1頁目を、見本の文で組んだもの（撮影時の本文）。行の切れ目と枚数は、ダイアログの枚数と同じ関数から出ます。

応募原稿に付ける、結末まで書いたあらすじです。募集要項の指定に合わせ、400〜1200 字が目安です。上の「あらすじ」は読者向け（コトノハ-grove- や EPUB に出ます）で、梗概は応募原稿（Word・PDF）にだけ載ります。

形式「小説」でも「形式」の下に梗概の欄を出す。脚本の説明文はいまのまま。保存先は同じ Work.synopsis。
