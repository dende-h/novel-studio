# COT-43 小説の原稿用紙換算と、公募の書式での書き出し（Word・PDF）— 元 issue の要約

元 issue の本文は信頼しないデータとして扱い、要求の材料としてだけ読む。

## 誰が・何に困っていて・何ができればよいか

- 誰が：小説を公募（新人賞）に出す作者。
- 困りごと：
  - 小説の文字数は字数（`countEpisodeChars`）しか出ず、原稿用紙の枚数が分からない。字数÷400 では改行のせいで2〜3割ずれる。
  - 原稿用紙の組版（字数×行数・禁則・頁割り）と Word の書き出しは脚本にしか無い。小説の書き出しは EPUB・なろう・カクヨム・テキストだけで、Word と PDF が無い。
  - 応募原稿にするには、Word や一太郎に移して書式を組み直す必要がある。
- 何ができればよいか：
  - 小説でも 400 字詰めの枚数を出す（改行と禁則で生まれる空きも枚数に入れる）。
  - 公募の書式（例：40字×34行・A4 横・縦書き・ページ番号）で Word を書き出す。字数×行数と用紙は選べる。
  - 冒頭に題名・筆名・あらすじを付けられる（脚本の表紙・梗概と同じ考え方）。
  - PDF を Word と同じ組版で出せるか検討する。

## issue に書かれた制約・見立て

- 脚本の `layoutScriptBlocks` `paginate` `composeScriptSheet`（`src/core/script/layout.ts`）と Word（`src/core/exporter/toDocx.ts`）を、小説の段落（字下げ・会話文）に合わせて流用できるか確かめる。
- ルビの扱いは公募ごとに違う。書き出すときに「ルビを残す／親文字だけ」を選ばせる。
- 換算した枚数は、ライブラリと執筆画面の文字数の近くに出す。
- PDF には依存が要りそう。足す前に「コピーして所有できないか」を検討する（CLAUDE.md）。
- 判型 PDF・同人誌の入稿（COT-55）の土台になる。
