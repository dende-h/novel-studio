# 要件定義 — COT-43 小説の原稿用紙換算と、公募の書式での書き出し（Word・PDF）

## 背景と目的

公募に出す小説の作者は、応募規定の枚数（400 字詰め換算や「40字×34行で何枚」）を確かめながら書き、最後は規定の書式に組んだ Word か PDF を出す。いまのコトノハは小説の字数しか出さず（`src/core/stats/index.ts:26-30`）、原稿用紙の組版と Word の書き出しは脚本にしか無い（`src/core/script/layout.ts:142-172`・`src/core/exporter/toDocx.ts:258-295`）。
小説でも原稿用紙の枚数を出し、公募の書式（字数×行数・用紙・縦書き・ページ番号）で Word と PDF を書き出せるようにして、Word や一太郎に移さずに応募原稿まで仕上げられるようにする。

## 機能要件

### FR-1 小説の原稿用紙換算（純関数）
- 流し込みの規則（本文は書き換えない。打ってあるとおりに組む）
  - 1段落を1つ以上の行にする。行頭の字下げ（全角・半角の空白）は打ってあるとおりにマスを使う。足しも削りもしない
  - 折り返しは `wrapLine` と同じ禁則：行頭禁則の追い出し・行末禁則の送り・句読点のぶら下げ（ぶら下げた句読点はマスを使わない＝行の字数を超えてよい）
  - 折り返した2行目以降は字下げしない（会話文も同じ）
  - 空の段落は空行1つ（続けて打てば続けて数える。小説では空行は作者の意図なので畳まない）
  - 話の末尾の空行は数えない
  - 1文字1マス。半角の英数記号もそれぞれ1マスに数える（全角に直す・2文字で1マスにする、はしない）
  - ルビは親文字だけ。傍点は本文のまま。`[[参照]]` は表示される名前
- 枚数は、流し込んだ行を頁に切った頁数。頁の先頭の空行は詰めない（打ってあるとおり）。話をまたいで続ける（話ごとに改ページしない＝FR-7 の既定）
- 受け入れ条件
  - Given 字下げ付きの段落「　あいう」（1行に収まる） / When 20字×20行で数える / Then 1行
  - Given 21字の段落（字下げなし） / Then 2行（20字＋1字）
  - Given 20字目の次が「。」の21字の段落 / Then 1行（句読点をぶら下げる）
  - Given 21字目が「」」の段落 / Then 「」」の直前の1字ごと2行目へ追い出す（`wrapLine` の既存テストと同じ振る舞い）
  - Given 空の段落を3つ続けた本文 / Then 空行3つとして数える。話の末尾にある空の段落は数えない
  - Given 合計 401 行の本文 / Then 21枚（20字×20行で 400 行＝20枚、401 行目で21枚目）
  - Given ルビ `｜漢字《かんじ》` を含む段落 / Then 「漢字」の2マスだけ数える
  - Given 本文が空の作品 / Then 0枚
  - Given 中身が空の話が2つある作品（字数 0） / Then 0枚（題名の行だけで1枚にしない。字数が 0 なら流し込まずに 0）
  - Given 同じ本文 / When 換算を2回呼ぶ / Then 同じ値（入力を書き換えない）

### FR-2 枚数を字数の近くに出す
- 出す場所（小説だけ。脚本の作品には出さない＝既存の原稿用紙プレビューがある）
  - ライブラリのカード：「12,345字 ・ 41枚」
  - ライブラリの行：「12,345字 ・ 41枚 ・ 3日前に編集」
  - サイドバーの作品情報：「3話 ・ 12,345字 ・ 41枚」
  - 執筆画面のステータスバー：いまの話の「◯段落 ・ ◯文字 ・ ◯枚」（下書きの本文から数える）。`sm` 未満の幅では「◯段落 ・」を省く
- 枚数はすべて「400字詰め換算」（20字×20行・FR-1）。書き出しで選んだ書式の枚数はここには出さない（書き出しダイアログに出す＝FR-3）
- 枚数のツールチップ（`title`）で「400字詰め原稿用紙に換算した枚数です」と分かるようにする
- 数え直すのは本文が変わったときだけ：ライブラリの一覧は作品ごとに `updatedAt` が変わったものだけ数え直す（自動保存のたびに一覧を作り直すため `src/ui/store/editorStore.ts:550`）。サイドバーは開いている作品が変わったときだけ、ステータスバーは下書きが変わったときだけ数える
- 受け入れ条件
  - Given 小説の作品 / When ライブラリを開く / Then カードと行に字数と並んで「N枚」が出る
  - Given 脚本の作品 / Then カードと行に「枚」は出ない（いまと同じ）
  - Given 本文が空の小説 / Then 「0字 ・ 0枚」
  - Given 中身が空の話が2つある小説 / Then 「0字 ・ 0枚」
  - Given 執筆画面で本文を打つ / When 入力が反映される / Then ステータスバーの枚数がいまの話の下書きで更新される（保存を待たない）
  - Given 作品が 20 個あるライブラリ / When 1つの作品を自動保存する / Then 流し込みは保存した作品の1回だけ走り、ほかの 19 作品は前の値を使う（数えた回数をテストで数える）
  - Given 狭い画面（`sm`＝640px 未満・モバイル） / Then ステータスバーにも枚数が出る。幅を空けるため、`sm` 未満では「◯段落 ・」を省き、「◯文字 ・ ◯枚 ・ 今日 +◯字」を1行に出す（393px 幅で折り返さない）

### FR-3 応募原稿（Word）の書き出し
- 書き出しダイアログ（小説の作品だけ）に「応募原稿」を足す。説明は「公募の書式（字数×行数・用紙）で、縦書きの Word か PDF に組んで」
- 書式（字数×行数）
  - よく使う書式から選ぶ：20字×20行（400字詰め）・40字×30行・40字×34行・42字×34行
  - 「指定する」を選ぶと、字数と行数を数字で入れられる。範囲は用紙で決まり、A4 は字数 10〜50・行数 10〜50、B5 は字数 10〜43・行数 10〜50（B5 で 44 字以上は、1字の送りが最小の文字の大きさ 8pt を下回るため）。範囲外は書き出しボタンを押せず、欄の下に「字数は 10〜43、行数は 10〜50 の数で入れてください」のように用紙に合わせた範囲を出す
  - 用紙を A4 から B5 に変えて字数が範囲を超えたときも同じ案内を出す（値は勝手に直さない）
- 用紙：A4・B5（どちらも横置き・縦書き）。既定は A4
- 文字の大きさは、書式と用紙から自動で決める（字詰めに収まる大きさ。8〜14pt）。画面に「文字の大きさ ◯pt」と出す
- 出す .docx
  - 縦書き（tbRl）・横置き・行グリッドを字数×行数に合わせる。Word で開いたときの「ページ設定」の文字数・行数が、選んだ書式と一致する
  - 段落は本文の段落ごとに1つ。字下げは打ってあるとおり（スタイルで字下げしない）。空の段落は空の段落のまま残す
  - ページ番号は本文の1頁目を1として下中央に入れる（表紙・あらすじには入れない）
  - 書体は游明朝（脚本と同じ）
  - ファイル名は「<作品名>_応募原稿_<字数>x<行数>_<用紙>.docx」（例 `月と剣_応募原稿_40x34_A4.docx`）
- 枚数の表示：設定欄に「本文 N枚（40字×34行）・400字詰め換算 M枚」を出す。N は選んだ書式で FR-1 と同じ流し込みをした頁数（Word で開いたときの頁数とは、Word の組み直しで数枚ずれることがある。その旨を一行添える）
- 受け入れ条件
  - Given 小説の作品 / When 書き出しを開く / Then 形式の一覧に「応募原稿」がある。脚本の作品には無い（脚本は既存の「脚本（提出用）」）
  - Given 40字×34行・A4 / When Word を書き出す / Then docx の `w:docGrid` が `linesAndChars`、行数 34・字数 40 に相当する `linePitch`・`charSpace` を持ち、`w:textDirection` が `tbRl`、用紙が A4 横（16838×11906 twip）
  - Given 20字×20行・A4 / Then グリッドの値が脚本の A4 プリセット（`linePitch` 657・`charSpace` 29736・14pt）と一致する
  - Given 字数に 9 を入れる / Then 書き出しボタンが押せず、範囲の案内が出る
  - Given B5・字数 44 / Then 書き出しボタンが押せず「字数は 10〜43…」と出る。B5・字数 43 なら押せ、docx の `charSpace` が 0 以上
  - Given 範囲内のすべての字数×行数×用紙 / Then 文字の大きさが 8〜14pt、`charSpace` が 0 以上（テストで総当たり）
  - 「本文が空」の判定は、作品の字数（`countWorkChars`）が 0 のこと。話が無い作品も、話はあっても字数が 0 の作品も、空として扱う
  - Given 話が1つも無い小説 / Then 書き出しボタンが押せず「本文がありません」と出る
  - Given 空の話が1つだけある小説（字数 0） / Then 同じく押せず「本文がありません」と出る
  - Given 書き出した .docx / When Word（Microsoft 365）と LibreOffice で開く / Then 壊れたファイルの警告が出ず、縦書きで本文・ページ番号が出る（手動確認。e2e ではファイルの中身を検査する）

### FR-4 表紙とあらすじ
- 表紙：題名（作品名）と筆名（作品情報の著者）を頁の中央に置く。筆名が空なら題名だけ
- あらすじ：作品情報の「梗概」（`Work.synopsis`）を、見出し「あらすじ」の頁として本文の前に置く。空なら頁を作らない
- 小説の作品でも、作品情報に「梗概」の欄を出す。説明は「応募原稿に付ける、結末まで書いたあらすじです。読者向けの『あらすじ』とは別で、応募原稿（Word・PDF）にだけ載ります」。脚本の説明はいまのまま
- 書き出しの設定で「表紙（題名・著者名）」「あらすじ（梗概）」をそれぞれオン／オフできる。既定はどちらもオン。梗概が空なら「作品情報に梗概がないので付きません」と添え、オンでも頁は作らない
- 枚数（FR-3 の N）は本文だけを数える。表紙・あらすじは含めない
- 受け入れ条件
  - Given 筆名「月見」・梗概 600 字 / When 表紙とあらすじをオンで書き出す / Then 1頁目に題名と「月見」、2頁目から「あらすじ」、そのあと本文。ページ番号は本文の1頁目が1
  - Given 小説の作品の作品情報 / When 開く / Then 「梗概」の欄があり、入れた内容が保存される（脚本と同じ `Work.synopsis`）
  - Given 脚本で梗概を書いてから形式を小説に変えた作品 / Then 梗概は消えずに残り、小説の応募原稿に載る

### FR-5 PDF（印刷して保存）
- 「出力」で「Word」「PDF（印刷）」を選べる
- PDF（印刷）は、FR-1 と同じ流し込みで組んだ頁を、1マス1文字で並べた印刷用の頁にして、ブラウザの印刷ダイアログを開く。利用者は印刷先に「PDF に保存」を選ぶ
- 頁は選んだ用紙の横置き。縦書き。下中央にページ番号（本文の1頁目が1）。表紙・あらすじは FR-4 と同じ
- 枚数（FR-3 の N）と PDF の頁数（表紙・あらすじを除く）は一致する
- PDF（印刷）を選んでいる間、設定欄に案内を出す：「印刷の画面で、送り先を『PDF に保存』に、倍率を 100%（または『実際のサイズ』）に、余白を『なし』か『デフォルト』にしてください」
- 書体は端末にある明朝（游明朝・ヒラギノ明朝・Noto Serif JP の順）。端末によって字形が変わることを案内に一言入れる
- 受け入れ条件
  - Given 40字×34行・A4・PDF（印刷） / When 書き出す / Then 印刷ダイアログが開き、プレビューの頁数が「本文 N枚」に表紙・あらすじの頁を足した数と一致する（Chrome で手動確認。自動テストでは印刷用 HTML の頁要素の数を数える）
  - Given 印刷用の頁 / Then 各頁に行が「行数」本以下、各行が字数（＋ぶら下げ1字）以下で並ぶ
  - Given ポップアップを止める設定 / Then 別ウィンドウを使わずに印刷できる（ページ内の見えない枠で印刷する）
  - Given モバイル（iOS Safari・Android Chrome） / Then 印刷の画面から PDF に保存できる（共有→プリント。手動確認）。書き出しの操作そのものはモバイルでも止めない
  - 実装の前に iOS Safari の実機で、ページ内の iframe の印刷が iframe の中身を印刷するか確かめる。親のページを印刷してしまう場合は、iOS では PDF（印刷）を選んだときに「iPhone・iPad では、Word で書き出してから PDF にしてください」と出し、ボタンを押せなくする

### FR-6 ルビ
- 「ルビ」で「振る」「親文字だけ」を選べる。既定は「振る」
- 振る：Word は Word のルビ（`w:ruby`）にする。PDF（印刷）は `<ruby>` で振る（マスの外に小さく出す。マスは親文字の字数だけ使う）
- 親文字だけ：読みを落として親文字だけにする
- `[[参照]]` の中に重ねたルビ（参照の `children` の `ruby`）も、同じ設定に従う（振る なら振り、親文字だけ なら親文字だけ）
- 枚数はどちらでも親文字で数える（FR-1）
- 受け入れ条件
  - Given `｜漢字《かんじ》` / When 振る で Word / Then `w:ruby` の親が「漢字」、読みが「かんじ」
  - Given 同じ / When 親文字だけ / Then 本文に「漢字」だけが入り、「かんじ」はどこにも出ない
  - Given ルビを含む本文 / Then 「振る」「親文字だけ」で枚数の表示が変わらない

### FR-7 話の題名と改ページ
- 「話の題名を見出しにする」（既定オン）：話の題名をその話の最初の行に置き、次に空行を1つ置く。話が1つだけの作品では出さない（作品名と重なるため）
- 「話ごとに改ページする」（既定オフ）：オンにすると、2話目以降の頭で改ページする
- どちらも枚数（FR-3 の N）に反映する。400字詰め換算（FR-2）は既定の設定（題名あり・改ページなし）で数える
- 受け入れ条件
  - Given 3話の作品 / When 既定で書き出す / Then 各話の頭に題名の行があり、改ページせずに続く
  - Given 話ごとに改ページをオン / Then 2話目・3話目が新しい頁から始まり、枚数が増える
  - Given 1話だけの作品 / Then 題名の行は出ない（オンでも）

### FR-8 設定を覚える
- 書式（字数×行数）・用紙・出力（Word／PDF）・ルビ・表紙・あらすじ・話の題名・改ページの選択を、その端末に覚える。作品をまたいで同じ設定を使う
- 覚えた値が読めない（壊れている・範囲外）ときは既定に戻す
- 受け入れ条件
  - Given 42字×34行・B5 で書き出した / When 別の作品で書き出しを開く / Then 42字×34行・B5 が選ばれている
  - Given ブラウザの保存領域が使えない（プライベートモードなど） / Then 既定の設定で開き、書き出しは止まらない

## 非機能要件

- 性能：ライブラリの一覧で全作品の枚数を数えても、一覧の表示を目に見えて遅くしない。10 万字の作品 1 つの換算が 50ms 以内（Node のテストで計測の目安を置く）。執筆画面の枚数は下書きが変わったときだけ数え直す
- オフライン：すべて端末の中で完結する（通信しない）
- プライバシー：原稿を外に送らない。印刷用の頁もページ内で作る
- アクセシビリティ：書式の選択はボタン（`aria-pressed`）、数字の欄はラベル付き。範囲外のエラーは欄に `aria-invalid` と説明を結びつける
- 無料／有料・ゲスト：書き出しはゲストを含め全員が使える（既存の EPUB・脚本の書き出しと同じ）

## 後方互換性チェック（CLAUDE.md の各項目）

- スキーマ：変更なし。梗概は既存の `Work.synopsis`（optional）をそのまま使う。スキーマのコメントだけ「脚本と小説の応募原稿が使う」に直す
- 旧形式の読み出し：該当なし（新しい欄を読まない）。`synopsis` が無い旧作品は空として扱う
- 表示先の維持：字数の表示は消さず、枚数を足すだけ。脚本の「脚本（提出用）」と原稿用紙プレビューは変えない。梗概の欄は脚本ではいまのまま、小説にも出るようになる
- 部分更新で他の欄を落とさない：作品情報ダイアログは、いまも `synopsis` を初期値に持って保存している（`workRepository.ts:31-32` のコメント）。小説でも同じ経路を通るので、梗概を触らなかった保存で消えない
- 削除は明示操作だけ：該当なし
- 配信契約（publish・同期 API・MCP）：変更なし。`WorkSummary` に足す枚数は画面用の派生値で、保存も送信もしない

## 仮定と未決事項

- 仮定：公募の書式は「縦書き・横置き・下中央のページ番号」で足りる（issue の例と講談社ラノベ文庫新人賞の規定）
- 仮定：「400字詰め換算」は 20字×20行に、本文を打ってあるとおりに流し込んだ頁数とする（公募ガイドの説明と同じ考え方）。字下げの無い段落に字下げを足して数える、はしない（推敲画面の「字下げ」で直す）
- 仮定：PDF は依存を足さずに「印刷して保存」で出す。Word の組版と完全には一致しないことを画面で伝える
- 未決：表紙に「400字詰め換算 ◯枚」を載せるか（規定で求めるところがある。載せるなら表紙のオプションに足すだけで済む）
- 未決：梗概の上限 1200 字（`MAX_SYNOPSIS_LENGTH`）を小説でも同じにするか。規定は 800〜2000 字と幅がある
- 未決：PDF を将来「ファイルとして直接作る」に切り替えるか（COT-55 の判型 PDF で必要になったら、そこで依存か自前実装を決める）

## 対象外

- 横書きの応募原稿
- 本名・住所・連絡先など応募者情報の入力と表紙への印字
- テキスト（.txt）の応募原稿（既存の Web 投稿形式で代替）
- 判型 PDF・段組・同人誌入稿（COT-55）
- 脚本の書き出しと枚数の振る舞いの変更
