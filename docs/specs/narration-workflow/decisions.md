# 朗読制作：2026-11-07の合意
本書を旧設計より優先する。
- 声・スタイルは話ごと。旧作品設定を初期値として継承し、個別指示を保持。
- 既成声サンプル、任意の冒頭約200文字スタイル試聴、一話生成、部分修正の順。スタイル試聴は文字枠を消費せず同条件を再利用。新条件の回数はサーバーで制限。公開上限は原価評価後に決定。
- 本文は自然な文章表示。クリックで文・台詞、ドラッグで語句・複数文。指示の範囲と生成区間を区別。右上の解除、余白、同じ文、Escで全体へ戻る。
- 部分修正は「選択部分を修正して生成」。費用を隣接表示。採用しなくても成功分は消費。再生・比較・採用・元に戻すは消費しない。
- 比較は元／新の切替、一体のプレーヤー、一つの「こちらを採用」。前後も聴ける。自動再生・自動採用なし。
- 一話再生成は確認モーダルに費用・残り・上書き・MP3退避。全区間成功後に一括上書き。失敗時は既存音声を保持し、再試行で成功区間を再利用。
- 範囲別の指示と最新候補を保存。重複範囲の候補は新生成成功後に置換、失敗時は保持。置換の案内は生成ボタン近く。
- 途中の作業は本文・話一覧に表示。朗読内の移動は無確認、外への移動は確認して保存後に移動。生成は継続。タブを閉じる警告は未保存時だけ。
- 読み方は用語集と別。選択語を修正し「この作品の同じ表記にも使う」。専用管理画面は増やさない。箇所修正＞本文ルビ＞作品共通＞モデル。本文を書き換えない。
- 本文編集で影響区間だけ未反映。確実な対応は維持、不明な指示は確認待ち。自動再生成しない。
- 書き出しは採用中の音声。未反映・候補があれば確認。単話MP3、複数話は話別MP3のZIP。
- 枠不足は必要量／残りを表示し開始しない。失敗・未実行分は消費しない。送信結果不明は再送せず確認待ち。

stgのみへ反映。本番公開、価格変更、有料モデル解禁は対象外。


## 注釈を受けたUIの修正（2026-11-07）

- 右側は「一話の声とスタイル」か「この部分の読み方」の一方。全体設定への重複リンクを置かず、右上の「× 選択解除」、余白、Escで全体へ戻る。
- 「ひとり朗読／複数の声」は常時見える切替。「配役を設定」メニュー・話者一覧・用語集からの人物取得は使わない。複数の声は本文を選び、その範囲の声・スタイル・自然言語の演技を直接指定する。
- 速さと段落のあとの間はスタイルの直下に並べる。読み方の修正だけを別の折りたたみにする。
- 全体の演技は「演技を添える」を開いて入力。部分修正では「どう読んでほしい？」を直接表示する。
- 生成ボタンは右側に集約。「一話を生成／一話を再生成」「選択部分を修正して生成／もう一度修正して生成」とし、今回の消費文字数を隣に表示する。
- 元の読み／新しい読みを選び、一体の再生・シーク・時間表示で比較して「こちらを採用」。下部は通し再生、MP3保存はヘッダー。leafの色・文字・枠線を使う。
- 話別モードと範囲別スタイルを任意項目として保存する。旧配役は新モードを選ぶ際に本文の声指定へ移し、旧設定・採用音声は削除しない。ひとり朗読は語り手の声を使うが、範囲の声指定は複数の声に戻したときに復元する。


## 選択・読み仮名・通し再生の補正（2026-11-07）

- 文・台詞のクリックは選択への追加、選択済みの再クリックはその文だけ解除。Shiftは連続範囲。余白・右上・Escは全解除。本文はブラウザの範囲選択を妨げない要素で描画し、複数ブロックを前後どちら向きにもドラッグできる。
- 「読み方の修正」は生成ボタンより前。語句をドラッグすると開き、選んだ表記と読み仮名入力を対応させる。複数文を選んだ場合は範囲ごとの入力とする。音声への反映は修正生成時、本文を書き換えない。
- フッターは常設の通し再生・シーク・時間・「ここを直す」、その下に状態と使用文字数。通し再生と部分比較の音声・位置を独立して保持し、同時再生しない。通し再生ボタン1回で再生する。
- 声におまかせで演技指定のない読点には短い間を補う。生成原稿に任意の commaPause を保存し、API送信時だけ「、」の直後へ [short pause] を挿入。本文と利用者の消費文字数は変更しない。明示的な演技指示を優先し、既存音声や旧生成リクエストはそのまま保持する。
- 間の長さはモデルの解釈に依存し、固定ミリ秒を保証しない。タグの根拠は [Fish Audio公式のPacing仕様](https://fish.audio/blog/fish-audio-s2-fine-grained-ai-voice-control-at-the-word-level/)。補正は次回の生成から適用し、自動再生成はしない。


## 連続範囲と状態の見える化（2026-11-08）
- クリック選択は、最初の文と最後にクリックした文の間をすべて選ぶ。途中に穴を作らない。内側の文をクリックした場合はその文まで縮める。同じ文だけを再クリック・余白・右上・Escは解除。ドラッグも連続範囲。以前の飛び飛び指定を開く場合も間を含めて選択するが、保存済みの指示は消さない。
- サウンドノベルの場面区切りは朗読に表示せず、新しい朗読の間にも取り込まない。旧音声と旧スナップショットは保持する。
- 一話全体の新しい演技入力は置かない。スタイル・速さ・間を選び、演技は本文の部分指定で行う。既存の全体指示は例外一覧で内容を表示し、明示的に削除できる。
- 複数の声は「本文に声を付ける」を主画面にし、声を付けた範囲をカードで開き直す。基本の読み方は折りたたむ。話者一覧や用語集は使わない。選べる声が1種類ならその事実を表示する。
- 速さ・間の選択肢は「スタイル通り」「短め 0.35秒」など、狭い欄でも全文を読める短い表記にする。
- 本文とラベルに状態色を付ける。未生成＝灰、生成済み＝緑、比較待ち＝橙、変更・未反映＝紫、選択＝青。生成中・問題ありは必要時に凡例へ追加。色だけに頼らず文字ラベルを常時表示する。「色の見方」を原稿上部に固定する。
- 通常の「保存した指示」全件一覧は置かない。本文横の読み／声／演技のリンクから指定範囲を開く。本文対応が外れた指示、旧場面指定、既存の全体指示だけを「本文から開けない指示」に残す。生成後に確認すべき一覧ではない。
- 読点の間は段落末の結合時の無音とは別。前回の [short pause] はモデルに渡す指示であり、一定の無音を挿入する処理ではない。今回は効果を実音声で確認できていないため、読点問題が解決したとは扱わない。


## 2026-11-08 初回の部分生成と段落での操作

- 元の採用音声がない部分は、生成・音声保存の成功時に自動反映する。比較と「こちらを採用」は既存音声の再生成だけに表示する。初回と再生成が混在する選択でも、初回部分は自動反映、既存部分だけを候補として残す。
- 初回は「選択部分を生成」。反映後は「選択部分を聴く」で確認できる。再生成には文字数を消費し、採用・試聴には追加の生成を伴わない。
- 旧UIで残った初回の比較候補も、明示的な部分生成スナップショットがあり、採用音声がない場合は保存確認後に反映する。冒頭試聴や単なるキャッシュ音声は対象外。
- 画面のクリック選択は段落単位。離れた段落をクリックすると途中も含めた連続範囲になる。同じ段落を再クリックすると解除。文字ドラッグによる語句・段落をまたいだ選択は維持する。
- 状態タグは段落ごと・同じ状態ごとに1つにまとめる。部分ごとの色は維持し、段落内に生成済みと未生成が混在しても判別できる。自由記述の指示は選択範囲に保存する。
- 内部の生成単位（主に句点・閉じかっこ）は変えない。既存音声・指示・生成費用の単位を保つ。段落表示への変更は演技指示への音声モデルの追従精度や読点の間を保証するものではない。分割レベル切り替えは追加しない。
