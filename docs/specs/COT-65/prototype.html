COT-65 ・ UIプロトタイプ ・ 要件 COT-68 ／ 設計 COT-69

投稿サイトの ZIP を取り込み、全話をまとめて書き出す

「テキストから作品を作る」で投稿サイトのバックアップ ZIP を受け、話に分けて作品にします。「Web投稿形式」では、全話を ZIP（話ごとの .txt）か1本の .txt で書き出せます。番号は設計（design.md）の UI 節と対応しています。

カクヨムと小説家になろうは、実物の ZIP で形を確かめました。ノベルアップ+ は実物が無いので、届くまでは「見分けられない ZIP」として扱います。
