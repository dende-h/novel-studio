# 脚本形式

作品情報で「脚本」を選ぶと、プレビューが原稿用紙（縦書き 20字×20行）になり、枚数を見ながら書けます。
柱・ト書き・セリフは行頭の書き方で見分け、ト書きの3字下げや柱の前の余白は自動で揃います。
Tab でト書きの字下げ、Shift+Tab で解除。字下げした行で Enter を押すと次の行も字下げのまま続きます。
書き出しは「脚本（提出用）」です。Word（A4 または B5・縦書き 20字×20行・柱書き／ト書き／セリフの段落スタイル付き）か、体裁を整えた .txt を選べます。ページ番号は本文の 1 頁目から入ります。表紙・登場人物表（用語集の「人物」）・梗概（作品情報で書く結末までのあらすじ）を付けられます。
書式チェックでは、セリフ末尾の句点、縦書きの算用数字、カメラワークの指示、用語集にない話者も確認できます。
プレビューは横書き 40字×40行にも切り替えられます。EPUB・なろう・カクヨムへの書き出しは小説の作品だけです。
本文の文字は、形式を切り替えてもそのままです。

複数の端末で同期している場合は、各端末でアプリを更新してから形式を選んでください。
旧版のアプリで保存すると、脚本の指定が外れることがあります。本文は残り、作品情報で再び「脚本」を選べます。

grove での脚本表示は公開先の対応が必要です。leaf の本番反映は grove の v7 対応後に行います。
