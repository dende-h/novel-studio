推敲画面と「直す箇所」のプロトタイプ

小説の推敲を、執筆画面とは別の「推敲」画面に移します。指摘ごとに「直す」か「このまま」かを選び、直すと決めたものだけを執筆画面に出します。番号は design.md の UI 節と対応しています。

モックの文章とデータは説明用の例です。色はアプリのトークン（src/ui/index.css の --secondary-container・--secondary-color・--primary など）だけを使っています。本文の選択色だけはブラウザの選択表示をまねたものです。

1エディタ下の「推敲チェック」を無くす（小説）
2ツールバーに「直す箇所 N」（1件以上のときだけ）
3押すと直すと決めた箇所の一覧（その箇所へ移る／外す）
4選ぶと本文の該当文字列を選択
5サイドナビに「推敲」（無料会員以上・PC）
6推敲画面のヘッダ（話・確認する項目・解析の状態）
7本文は読むだけ。指摘に印
8「指摘｜分析」と絞り込み
9指摘のカードと判断のボタン
10分析（よく使う言葉・セリフと地の文）
