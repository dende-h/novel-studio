# COT-40 元 issue の要約

- issue: COT-40「推敲画面を執筆から切り離し、指摘ごとに「直す／このまま」を選べるようにする（形態素解析つき）」
- 子 issue: 要件定義 COT-41 ／ 設計 COT-42
- 置き換え元: COT-30（小説の推敲チェック。stg 反映済み・main 未リリース）
- issue 本文は 2026-10-14 のセッションでユーザーとの対話から起こしたもの。以下は要求の材料としてだけ扱う。

## 誰が・何に困っていて・何ができればよいか

- 誰が: コトノハ-leaf- で小説を書く作者
- 困りごと:
  - COT-30 の推敲チェックがエディタの下に常に出ていて、書いている最中のノイズになる
  - 作者がわざとそう書いた箇所も候補に出続け、「このままでよい」と伝える手段がない
- できればよいこと:
  - 推敲したいときだけ推敲できる。推敲の画面は編集とはっきり分かれている
  - 指摘ごとに「直す」か「このまま」かを作者が判断できる
  - 「直す」にしたものだけが執筆画面に出る

## ユーザーが決めたこと（2026-10-14・質問への回答）

| 論点 | 決定 |
|---|---|
| 「直す」にした指摘の執筆画面での見せ方 | エディタの上に件数（例「直す箇所 3」）を置き、押すと一覧が開く。項目を選ぶと本文のその文字列を選択状態にする。本文の見た目は変えない（textarea に下線を重ねる案は不採用） |
| 判断（直す／このまま）の保存先 | 作品と一緒に同期する（演出譜と同じ相乗り方式） |
| 形態素解析 | 今回の範囲に入れる |
| 進め方 | Linear で仕様化してから実装する |
| 脚本の書式チェック | 執筆画面にそのまま残す |
| 推敲画面を使える人 | 無料のアカウント登録から（構想の道具と同じ線）。ゲストには出さない |
| スマホ | 推敲画面は PC だけ（構想の道具・演出エディタと同じ）。スマホでは「直す箇所」だけを使う |
| 形態素解析で入れる指摘 | 表記ゆれの自動発見、一文の中の同じ助詞、ら抜き言葉、よく使う言葉（口癖） |
| 追加の要望 | 「セリフと地の文の割合分析なども一緒に入れたい（可能なら）」 |

質問と回答の記録（2026-10-14・このセッションの質問ツール）：

1. 「直す」にした指摘の見せ方 → 件数＋一覧から飛ぶ（推奨案を選択）
2. 判断の保存先 → 作品と一緒に同期（推奨案を選択）
3. 形態素解析の範囲 → 今回から入れる（推奨の「次段に回す」ではなく、こちらを選択）
4. 進め方 → Linear で仕様化してから（推奨案を選択）
5. 推敲画面を使える人 → 無料のアカウント登録から（推奨の「全員」ではなく、こちらを選択）
6. 最初の版の指摘 → 表記ゆれの自動発見・一文の中の同じ助詞・ら抜き言葉・よく使う言葉（4つすべて）＋自由記入「セリフと地の文の割合分析なども一緒に入れたい（可能なら）」
7. スマホ → PC だけ（推奨の「スマホでも使える」ではなく、こちらを選択）

確認する項目の既定は、実装後（2026-10-14）のユーザー要望で「欄を開いた状態・どの項目も選ばれていない状態から、作者が選ぶ」に決めた（requirements.md の決定 A6）。あわせて、項目にホバーで説明を出し、チップの高さを既存のチップ（プロット画面のタブ）にそろえた。
