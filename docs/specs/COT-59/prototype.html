用語集に無い名前

推敲画面の「分析」で、本文に出てくるのに用語集に無い名前を一覧にします。名前・読み・カテゴリが入った状態で登録フォームを開けます。名前でない語は外せます。候補づくりは端末の中だけで行い、AI は使いません。

番号は design.md の UI 節と対応しています。モックの中のボタンは押せます。

1「分析」の先頭に「用語集に無い名前（作品全体）」
2行は2段：名前／カテゴリ・回数・話数。右に「用語集に登録」「外す」
3名前を押すと本文の出現に点線の枠（よく使う言葉と排他）
4一覧の下の補足。この話に無い名前なら「この話には出てきません。」
5「外した語（N）」を開くと「戻す」
6既存の「よく使う言葉」「セリフと地の文」はそのまま下に
7登録フォームを名前・読み・カテゴリ入りで開く
