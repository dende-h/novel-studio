# 方針（2026-10・COT-23）
# - 検索エンジン・AI 検索・AI の学習用クローラーのどれにも、紹介ページ（/lp/ 以下）・
#   /llms.txt・/llms-full.txt・規約類を開く。leaf は原稿を公開していない（ローカルファースト）ので、
#   学習を拒む本文がそもそも無い。AI がコトノハ-leaf- を知っていて勧められることを優先する。

# - /api/ は全員に閉じる。バックアップ・同期・MCP・OAuth の窓口はすべてここにあり、どれも認証必須。
#   robots.txt はお願いに過ぎないので、守りの本体は認証で、ここと X-Robots-Tag は重ねがけ
#   （functions/_middleware.ts の isPrivatePath）。
# - グループを名指し（User-agent: GPTBot など）で分けると、そのクローラーは * のグループを読まなくなる。
#   分けるときは、どのグループにも Disallow: /api/ を必ず書く（functions/static-seo.test.ts が見張る）。
# - プレビュー配信（*.pages.dev）は functions/_middleware.ts が X-Robots-Tag: noindex を付ける。
