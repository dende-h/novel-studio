# トーン＆マナーと用語

## トーンの軸

LP（`public/lp/index.html`）が基準。特徴——

- **静かで誠実**。機能を盛らず、できること・できないことを事実で言う。
  例:「原稿はブラウザ内（あなたの手元）に保存され、勝手に外部へ送られません」
- **書き手が主語**。プロダクトの凄さではなく、ユーザーの「書く」がどう変わるかを語る。
  例:「一度ひらけば、ネットが無くても書き進められます。電車のなかでも、旅先でも」
- **読点でつくるリズムと余韻**（LP・大見出し限定）。例:「原稿は、あなたの手元に。」「書く日々に、寄り添う道具。」
  UI の実務文言（ボタン・エラー等）ではこの詩情は使わず、簡潔に言い切る
- **押し付けない**。命令・勧誘の圧を出さない。「ぜひ」「まずはお気軽に」は使わない
- **不安で売らない**。端末故障などのリスクは静かに事実として伝える。
  例:「その一方で、端末は壊れることも、失くすこともあります。だから〜」
- 有料機能の案内は率直に。「ここから先は、有料のクラウド版の機能です」と先に言ってから中身を語る

## 文体規則

- 本文は敬体（です・ます）。見出しは体言止め・言い切り可
- 数字・価格は具体的に（「月額 ¥500、年額 ¥4,800」）。「お得」「今だけ」等の煽りは使わない
- 漢字は開きぎみ（ひらけば・ひとり・とき・こと）。ただし既存文言との統一を優先
- 「AI」「MCP」等の略語は、初出の近くで何が起きるかを平易に添える
  （例: MCP 説明の「原稿はあなたが選んだ AI サービスに送られます」）

## 用語表 — 既存 UI と揃える

| 使う | 概念 / 補足 |
|---|---|
| コトノハ-leaf- | **執筆アプリ**（このリポジトリ）の名前。文中でも省略せずこの表記。旧「コトノハ」表記は使わない |
| コトノハ-grove- | **読者向けの公開サイト**（別サービス・`novel-platform`）の名前。旧「公開サイト」表記は使わない。日本語に続けるときは LP と同じく前後に半角スペース（「コトノハ-grove- へ投稿」） |
| 原稿 / 本文 | ユーザーが書く小説そのもの |
| 作品 / 話 | Work / Episode。UI には「エピソード」表記も残っているため、**触る画面の既存表記に合わせる** |
| 用語集 | 人物・場所等の事典。**コトノハ-grove- に出る**（作者メモ欄を除く） |
| 世界観設定 | 作者専用・公開されない。用語集と混同させない書き分けが必須 |
| 構想の道具 | プロット・マインドマップ・相関図・アウトラインの総称（無料のアカウント登録で解禁） |
| ネタ帳 / 執筆の記録 | `/ideas` / `/activity` の画面名 |
| クラウド版 | 有料プラン。同期・クラウドバックアップ・AI 連携（MCP） |
| 同期 / バックアップ | 別概念。混ぜない（同期=端末間、バックアップ=復元用の控え） |
| ゴミ箱 / 下書き | 既存 UI の語 |
| ペンネーム / 作者名 | **別物。語を混ぜない。** ペンネーム＝コトノハ-leaf- の中の名前（ヘッダ・掲示板・新しい作品の著者）。作者名＝コトノハ-grove- に作者として出る名前。片方を変えてももう片方は変わらない（`docs/requirement/09-board.md` D-PENNAME-GROVE） |

## 禁止・注意語

書き上げたドラフトをこのリストと突き合わせる（toc-copy スキル §3 の自己検査）。

**使わない（見つけたら直す）**: 革新的・画期的・次世代の・究極の・シームレス・ソリューション・
豊富な機能・充実の機能・まずはお気軽に・いかがでしょうか・非常に重要・言うまでもなく

**文脈で判断（原則使わない。使うなら理由を持つ）**: 〜を実現します・〜してみませんか・
あなたの〜をサポートします・など様々な・ぜひ（1画面1回まで）・〜することができます（→「〜できます」）

リストにない語でも、この系統（誇張・網羅アピール・定型勧誘・翻訳調）に頼らず事実で書く。
