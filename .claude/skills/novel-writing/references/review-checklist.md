# 目視レビューのチェックリスト — 機械が見ないもの

textlint が収束したあと、初見の読者のつもりで通読しながら確認する。
指摘は「どの行・どの文か」を特定して挙げる。

## 整合性

- [ ] 視点のブレ: 視点人物以外の内心・視界外の描写が混ざっていないか
- [ ] 時制の乱れ: 過去形基調の地の文に現在形が意図なく混ざっていないか（臨場感狙いの現在形は正当）
- [ ] 設定との矛盾: 固有名詞の表記・呼称・設定が用語集/世界観設定/既出話と一致するか（MCP なら
      `get_glossary` / `get_world` と照合。新規の固有名詞が出たら用語集への追加を提案）
- [ ] 時間・空間の連続性: 移動・時刻・持ち物が場面間で飛んでいないか

## 構成

- [ ] 冒頭: 最初の3行で場面（誰が・どこで・何をしている）が立ち上がるか。設定説明から始まっていないか
- [ ] 引き: 話の末尾に次を読ませる力（未解決・変化・予感）があるか
- [ ] 場面の目的: 各シーンが「何かを変える」か。何も動かないシーンは削るか統合を検討
- [ ] 会話と地の文のバランス: 会話だけが数十行続く、地の文だけが延々続く箇所に意図があるか

## 文章の質

- [ ] 感情説明への逃げ: 検出辞書にない形でも「嬉しかった」「怖かった」で済ませていないか
- [ ] 重複描写: 同じ情報・同じ心情を言い方を変えて2度書いていないか
- [ ] 音読リズム: 声に出すつもりで読んで、つかえる文・息が続かない文がないか
- [ ] 会話文の声: 台詞だけ読んで誰の発言か区別がつくか（全員が同じ口調になっていないか）

## 報告の形

診断モード（書き換えない依頼)のときは、所見を「良い点 → 直すと効く点（行指定） → 機械検査の結果概要」の
順で返す。スコアめいた数値は根拠を示せる範囲でのみ使う。
