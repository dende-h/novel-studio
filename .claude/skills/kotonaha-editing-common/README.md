# kotonaha-editing-common — 編集スキルの共有リファレンス

ここはスキルではない（`SKILL.md` を持たない）。コトノハ-leaf- のコネクタ（MCP）を使って
設定を詰める 4 つのスキルが、共通で読む資料を置く場所。

| ファイル | 中身 | 読むスキル |
|---|---|---|
| `references/kotonaha-mcp.md` | 器の分かれ方・読み書きの手順・事故の起きる場所 | 4 つすべて |
| `references/editor-stance.md` | 編集者としての立ち方と、一論点ずつ掘る進め方 | 4 つすべて |

参照するスキル:

- `.claude/skills/glossary-deepdive/` — 用語集の 1 項目を掘る
- `.claude/skills/world-deepdive/` — 世界観設定の枠を掘る
- `.claude/skills/beat-rework/` — ビートを組み直す
- `.claude/skills/story-audit/` — 作品全体を点検する

直すときは 4 つのスキルすべてに効くことを意識する。ここは共有部品なので、
1 スキルの都合で書き換えると他の 3 つがずれる。
